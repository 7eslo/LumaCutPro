# LumaCut Pro - iOS App

تطبيق آيفون أصلي لقص الصمت مع دعم الدقات العالية والبت رايت العالي.

## المميزات
- يدعم 4K, 6K, 8K, ProRes, HEVC 10-bit
- يحافظ على البت رايت الأصلي (Passthrough)
- معالجة محلية 100% - لا سيرفرات
- مصمم للعمل مع LumaFusion

## كيف تبني الـ IPA

1. افتح المشروع في Xcode 15+
2. غيّر Bundle Identifier إلى شيء خاص بك
3. وصل آيفونك
4. Product > Archive > Distribute App > Ad Hoc
5. راح تحصل ملف .ipa جاهز للتثبيت

أو استخدم AltStore للتثبيت بدون حساب مطور مدفوع.

## المتطلبات
- iOS 16+
- iPhone XS أو أحدث (لمعالجة 4K)
